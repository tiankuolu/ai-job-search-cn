# 岗位申请操作

读取工作区根目录 `AGENTS.md`，再读取材料目录 `个人资料/` 的候选人档案、偏好与事实证据。
核对目标公司岗位目录中的 `岗位JD.md`，或 `岗位记录/inbox/` 中的完整岗位原文。
读取与核心要求相关的项目代码及实验记录，完成匹配分析。

申请包保存到 `岗位记录/evaluated/<岗位标识>-application.md`。
在已有公司岗位目录中更新定制简历和 `打招呼语.md`；新的岗位建立 `公司-岗位-实习津贴/` 目录。
简历使用材料目录的 `简历基版.tex` 和当前岗位源文件，按实际职责调整项目顺序与条目。

完整简历需要实际编译，检查 A4 单页、文字提取、联系方式、链接和版面。
模型仅输出申请包时，报告申请包的实际完成状态。
外部发送与提交遵循用户授权；记录用户确认的真实投递状态到 `岗位记录/evaluated/delivery-status.csv`。

Python 用法见项目 README。Codex、ZCode 根据相同的档案、证据和工作流完成任务。
