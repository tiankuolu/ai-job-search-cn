# 执行办公任务评测

```powershell
. ./runs/run-integration.env.ps1
py -3.11 -m jobsearch_agents.delivery.benchmark .artifacts/office-evaluation-新日期
```

任务来自已有真实需求、岗位、生成记录和文件，覆盖事实关联、事实编号、局部修改、历史版本归属、结构化修改、人工导出、岗位文件解析、招聘网址解析及导出名称。正式业务程序处理实际 HTML、PDF、OCR、浏览器和模型请求，按任务保存验收标准、源码、测试代码、耗时和逐项结果。检查失败会保留记录并终止验收。

运行目录包含任务结果和 JUnit XML、实际工作文件、源码快照与摘要。`fact-snapshots` 保存本次事实来源，`relevance-review.json` 保存本次读取的真实申请包的完整 JD、生成正文、项目选择、事实关联及来源摘要。申请包数量随真实工作台内容变化。

岗位职责覆盖、任职要求覆盖、项目选择依据与事实支持分别等待人工判断。自动检查通过不能直接作为岗位语义相关性结论。

`recorded-revision.json` 使用真实审查后修改记录，保存 JSON Patch 操作及字段类别。新增、删除、替换操作保留原义；事实依据修改、项目正文修改和技能修改分别记录，具体修改动机由人工结合轨迹判断。

评测输出保存在项目 `.artifacts`，不影响生产工作台已有岗位、材料和申请状态。生成与导出仍按现有操作入口执行。
