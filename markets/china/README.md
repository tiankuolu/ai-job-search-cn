# 中国实习求职规则

本目录维护资料模板、招聘来源、沟通模板与工作流。
个人资料与求职产物保存在工作区的简历材料目录。
具体路径与文件命名见 `workflows/runtime.md`，任务映射见 `workflows/index.md`。

- `profile/`：资料结构模板，个人事实填入材料目录的 `个人资料/`。
- `templates/`：中文打招呼语、私信、求职信与面试回答模板。
- `sources.json`、`search-queries.md`：公开招聘来源与查询配置。
- `workflows/`：初始化、搜索、分析、申请、排序和面试准备规范。

中文正文使用完整词语与正常中文标点，代码、Markdown 语法、英文术语和文件路径保持原有格式。
共同的机会判断、事实约束与表达要求遵循工作区根目录 `AGENTS.md`。
