# 申请材料

按 runtime.md 读取完整 JD、个人资料、对应评估和已有公司调研。
中文沟通模板位于项目 `markets/china/templates/`。
申请包写入材料目录 `岗位记录/evaluated/<岗位标识>-application.md`。

申请包使用 Python writer 提示词中的章节：`Supported Positioning`、`BOSS Greeting`、`Recruiter Message`、`Chinese Cover Letter / Email`、`Resume Delivery Note`、`Resume Tailoring Suggestions`、`Interview Focus`、`Gaps To Keep Honest`、`User Confirmation Needed`。
打招呼语结合岗位核心职责、一项最强相关成果与已确认到岗条件；私信和求职信保持相同事实。
对外正文直接表达相关能力，内部准备与待确认事项保存于申请包的内部章节。
只使用有依据的经历、技能、指标和个人承诺，未经用户表达意愿不得承诺额外试做。

用户要求简历时，读取材料目录的 `简历基版.tex` 和当前岗位源文件，按岗位调整项目顺序与条目。
继续使用已有公司岗位目录；新岗位建立 `公司-岗位-实习津贴/`，保存 JD、简历源文件、成品及 `打招呼语.md`。
实际编译并完成 A4 单页、文字和版面检查，再报告文件完成状态。确认可直接发送的正文与文件后，按用户授权处理外部发送。
