# 公开岗位搜索

按 runtime.md 读取材料目录的 `个人资料/preferences.md` 与 `candidate.md`。
招聘来源和查询模板读取项目 `markets/china/sources.json`、`search-queries.md`。
搜索目标根据职责、已确认的城市、身份和到岗条件确定。

使用当前会话的联网搜索与网页读取工具，读取完整公开 JD。
Python `scrape` 使用项目的牛客公开来源实现，命令参数见帮助。
来源页面缺少正文时记录具体待补充字段，禁止推断职责、薪资或学历条件。
搜索和访问遵循用户授权及来源要求，账号操作和外部发送需要相应授权。

完整原文保存到材料目录 `岗位记录/inbox/<公司>-<岗位>.md`，保留来源网址、保存日期、职责、要求与已公开条件。
已有公司岗位目录保留 `岗位JD.md`，重复岗位先核对来源和内容。
抓取去重状态保存到 `岗位记录/seen_jobs.json`，投递状态读取 `岗位记录/evaluated/delivery-status.csv`。
只展示符合用户条件的岗位，相关正文仍待补充时说明具体缺失。
