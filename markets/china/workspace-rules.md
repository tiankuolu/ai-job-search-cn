# 求职工作区规则

## 2. 个人资料

身份、教育、联系方式、实习安排与求职偏好采用用户当前确认的资料。
未确认的个人承诺不得推测；用户手动修改的材料保持当前内容。

## 4. 项目证据

项目经历采用具有明确来源的真实事实，区分本人贡献、实现内容和实际验证结果。
指标保留所属项目、样本规模、配置和比较条件，未完成的功能保持对应状态。

## 6. 申请材料

按完整岗位职责选择相关事实和项目顺序，采用 STAR 组织项目经历。
教育背景与 GPA 使用当前个人资料，技能与荣誉遵循当前偏好。
使用可编辑 HTML 与 A4 单页 PDF，导出后检查文字、链接、字号和页面边界。
人工修改后的正文保持当前内容，直接导出并验证文件。

## 7. 招聘沟通

沟通内容采用当前已确认的身份、相关成果与到岗条件。
发送消息、提交申请和联系招聘者按用户授权执行，记录真实结果。
